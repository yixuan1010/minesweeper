# Minefield｜踩地雷

一個可直接部署到 GitHub Pages 的純前端踩地雷遊戲。

## 功能

- 初級（9×9／10 顆）、中級（16×16／40 顆）、專家（30×16／99 顆）
- 首次揭開一定安全，且會自動展開空白區域
- 滑鼠右鍵與手機旗標模式
- 計時器、剩餘地雷數、勝負提示與重新開始
- 響應式版面，支援手機與桌面瀏覽器

## GitHub Pages

將 `index.html`、`styles.css`、`script.js` 放在 GitHub repository 的根目錄，進入 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**，再選擇 `main` 與 `/ (root)` 即可。
